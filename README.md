# Shopify Beauty Customer Insights

A portfolio demonstration exploring how an e-commerce business could use customer and sales data to understand performance and make better decisions.

## Project files

- `Emmanuella_A._Shopify_Beauty_Customer_Insights_Dashboard (1).xlsx` — Excel workbook for exploring the dataset and analysis.
- `index.html` — portfolio webpage presenting the case study and service offer.

## About the case study

This is a demonstration project, not paid client work. The dataset is representative/synthetic, so the figures and findings should be read as an example of an analytical workflow rather than verified results from a real Shopify store.

The project is intended to demonstrate spreadsheet analysis, business-focused reporting, and communicating findings clearly.
